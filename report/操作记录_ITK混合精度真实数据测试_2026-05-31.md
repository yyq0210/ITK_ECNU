流水线（相对 **full_double** 为精度参考）：

| 路线 | 步骤 |
|------|------|
| **full_float** | float 输入 → RecursiveGaussian float |
| **hybrid** | float → cast double → Gaussian double → cast float |
| **full_double** | cast double → Gaussian double |

## 2. 加速比（墙钟 ms，5 次平均，σ=2）

| 真实数据 | float (ms) | hybrid (ms) | double (ms) | float / double | hybrid / double |
|----------|------------|-------------|---------------|----------------|-----------------|
| PNG 256² | 1.53 | 2.87 | 2.52 | **1.65×** | 0.88× |
| PNG slice | 1.18 | 2.39 | 2.01 | **1.70×** | 0.84× |
| MHA brain complex | 1.15 | 2.49 | 1.99 | **1.73×** | 0.80× |
| MHA 3 slices (σ=1.5) | 11.68 | 12.67 | 12.27 | **1.05×** | 0.97× |

**σ=5，PNG 256²：** float **1.61×** vs double；hybrid **0.83×**（cast 开销大于 double 节省）。

**σ=10，MHA complex：** float **1.84×** vs double。

**解读（真实数据）：**

- **2D 真实 MRI**：**全程 float 比 double 快约 65%～73%**；hybrid 因 **两次 cast** 反而 **慢于 double**（约 0.8～0.9×）。  
- **3D 薄层体**：三者接近（~12 ms），float 仅 **~5%** 优势（数据小、pad 后仅 4 层）。  
- **混合精度在此流水线下的「优化」**：若目标是 **速度** → 真实 2D 数据应 **直接用 float**；若目标是 **精度** → 本滤波器上 float 与 double **输出一致**（见下节），**不必 hybrid**。

## 3. 精度（相对 full_double）

| 数据 | σ | float max_abs / rmse | hybrid max_abs / rmse |
|------|---|----------------------|------------------------|
| 全部真实数据 | 2～10 | **0 / 0** | **0 / 0** |

对 **`SmoothingRecursiveGaussianImageFilter`** + 上述 **真实 MRI/MHA**，float 与 double 结果在逐像素比较下 **无可见差异**（max_rel=0）。  
原因：像素值范围与 ITK 该滤波器实现下，**float 已足够**；与合成棋盘结论一致。

**若要在真实数据上看到精度差异**，建议换：

- **配准/优化**（`ImageRegistration`，累积度量）  
- **多步迭代**（扩散、Level-set）  
- **MPI 大体数据 + 多 rank 归约误差**（`mpi_hybrid_precision_demo`）

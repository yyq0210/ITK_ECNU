## 4. 结论

1. **与 Example + 数据规模强相关**  
   - **小图 / 极快滤波**（256² Bilateral、Resample、DiscreteGaussian、SmoothGauss）：**16 核后几乎见顶**，96 核无意义甚至略慢。  
   - **大图 Bilateral**（1024²～**16384²**）：线程越多（至 96）收益越大；**4096²** 上 96 相对 16 约 **2.2×**，**8192² / 16384²** 上 96 相对 16 约 **2.2×**（单次测量）；**16384²** 单核约 **12 min**、96 线程约 **25 s**。说明先前 256²「只有十几核在跑」主要是 **并行工作量不足**，不是绑核失效。

2. **迭代扩散（CAD / GAD，50 次迭代）**  
   - 比 256² Bilateral **更耗时**（0.6 s / 0.5 s 单线程），但 **最佳线程数约在 16 附近**；**96 线程比 16 更慢**（同步/缓存/迭代依赖），**不适合盲目拉满 96 线程**。

3. **实践建议**  
   - **压测 / 展示多核**：**4096²～8192² Bilateral** 即可在 `htop` 中观察多核；**16384²** 适合单次演示（耗时长）。线程数可试 **64～96**。  
   - **再大**：2D 放大图可至 **16384²**（内存仍够）；再大需权衡单次 **>10 min** 单核时间；**真实 3D 体数据** 更接近业务。
   - **教学小 Example**：默认 **16 线程 + `taskset -c 0-15`** 即可。  
   - **迭代滤波**：以实测为准，**16～32** 往往优于 96。

## 1. 口径（不要改）

| 列 | 含义 |
|----|------|
| H `arm未绑核` | 无 `taskset`，ITK 默认 96 线程，`ms_double` |
| I `arm绑核` | `taskset -c 0-95`，未混合，`ms_double` |
| J | `H/I` |
| K 混合精度时间 | 绑核、`Image<float>`，`ms_float` |
| M | `I/K` |
| N | 误差（能比灰度单/双精度的才填） |

混合精度：同一套输入 float 跑一遍、double 再跑一遍。  
整数/标签/向量/投影/复数/RGB、以及 VNL LU 只吃 double 的网格求解：**只填 H/I，K/M 留空**。  
串行行（Fast Marching、ByReconstruction/HMaxima、细化、填洞、RegionGrowing）：H/I/J/K/M 全空。

DCU 四列（E/F/G/L）不填。

## 6. 按批次复测已测函数

通用命令（每个 bench 都支持）：

```text
precision_xxx_bench --list
precision_xxx_bench <image.png> [runs=3] [OperatorName]
```

绑核：`taskset -c 0-95 ./bench IMG 3 OP`  
未绑核：直接 `./bench IMG 3 OP`  
脚本里对每个 `--list` 里的名字循环，超时写入 `FAIL`。

| 批次 | 可执行文件 | 复跑脚本 | 输入 | 已测内容 |
|------|------------|----------|------|----------|
| 晚间主测 | `precision_pipeline_bench` | `run_1024_remeasure.sh` 等 | 官方图 / 1024 | RecursiveGaussian、Threshold、Resample、Gradient、Dilate、Normalize、Otsu、Maurer、Sobel、Median 链等 |
| 卷积 / Bilateral | `precision_conv_bench` `precision_bilateral_bench` | 同上 | 官方图 | Convolution、FFTConvolution、Bilateral |
| 扩散 | `precision_diffusion_bench` | 同上 | 官方图 | CAD、GAD、CurvatureFlow |
| 配准 | `precision_registration_bench` | 同上 | 官方图+平移图 | `ImageRegistrationMethodv4`、Mattes 等 |
| 扫模块 | `precision_modules_sweep_bench` | 同上 | 官方图 | 早期模块抽样 |
| 补缺 1 | `precision_fill_missing_bench` | `run_fill_missing.sh` | 1024 | 二值/标签/统计等 |
| 造数据 1–3 | 同一 bench + construct 脚本 | `run_construct*_1024.sh` | 1024 + 裁块 | LabelMap、位移场、复数 FFT、Voronoi 等 |
| Path / 已测网格 | `precision_path_mesh_bench` | `run_path_mesh_1024.sh` | 1024 + 球面网格 | Contour、PathToImage、已测 QuadEdge |
| 水平集 | `precision_levelset_bench` | `run_levelset_1024.sh` | 圆心距离图+Sigmoid | GAC 等可 New 的水平集 |
| 度量 / 点集 | `precision_metric_bench` | `run_metric_1024.sh` | 1024 + 抽样点 | Metricsv4、点集度量 |
| remain | `precision_remain_bench` | `run_remain_1024.sh` `run_remain_fix.sh` | 1024 / 小块 | 剩余能 `SetInput` 的并行接口 |
| extra35 | `precision_extra35_bench` | `run_extra35_1024.sh` | 小块造数 | DTI、反卷积、PolylineMask 等 34 个 |
| 第 3 类 | `precision_cat3_bench` | `run_cat3_1024.sh` | 程序造网格/路径/点集 | 开边界 QE、Simplex、形状先验、SpatialObject、标签点集、DomainMap |

## 10. 混合精度开关（复测时保持 ON）

`ITK_ENABLE_MIXED_PRECISION` 在 `build-yyq` 为 **ON**：

- Mean / BoxMean：float 像素用 float 累加
- CAD / GAD / CurvatureFlow：float 外壳、内部 double 迭代
- Gaussian / Bilateral：仍走官方 RealType

绝大多数函数只靠应用层 `Image<float>` vs `Image<double>`，不改 ITK 源码。
